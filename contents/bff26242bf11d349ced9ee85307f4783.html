Descargar Paneles y Fichas

UMLUseCase «CU-005»
Omnissiah :: Modelo de Requisitos :: «CU-005»Descargar Paneles y Fichas

Description

Motor de reportes que consulta la base de datos y el repositorio de imágenes para generar documentos finales en formato PDF imprimible.

Ficha Catastral: Vuelca la información estructurada (propietario, ubicación, construcción) en el formato oficial de la entidad.

Panel Fotográfico: Crea un documento visual donde se organizan las fotos cargadas, ajustando su tamaño y agregando automáticamente pie de fotos con la data del predio (código, fecha, ubicación).
